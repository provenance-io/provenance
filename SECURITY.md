# Security Policy

This repository participates in Provenance Foundation & Hastra's central security and bug bounty program.

Review the [central security policy](https://bugbounty.hastra.io/terms) for current scope, testing rules, bounty eligibility, reward guidance, safe harbor, and coordinated disclosure requirements.

## Reporting a Vulnerability

**Do not open a public GitHub issue.** Submit the vulnerability privately through our bug bounty submission form https://bugbounty.hastra.io.

To report a vulnerability without being eligible for the bug bounty program, please email security@provenance.io.

Testing against mainnet, public testnets, or any live deployment is prohibited. Use a local fork or controlled simulation only.
